## 关于函数级结论

本目录是这些结论**唯一的公开载体**：机制、调用链、结构体布局、站点与置信度标注都写在文档里。
逐函数的代码级还原不随本仓库发布；需要对照某个函数的具体行为时，见各篇文档中对应的段落。
