## 1. 结构体速查

### 1.1 `CString` / `EngineString`（= MSVC `std::string`，**32 字节**）

```cpp
struct CString {                                       // sizeof == 32
    union { char inline_bytes[16]; const char* pointer; } storage;   // +0x00
    std::uint64_t size;                                // +0x10
    std::uint64_t capacity;                            // +0x18
    const char* data() const { return capacity < 16 ? storage.inline_bytes : storage.pointer; }
};
static_assert(sizeof(CString) == 32);
static_assert(offsetof(CString, size) == 16);
static_assert(offsetof(CString, capacity) == 24);
```

★★ **SSO 分界 = 15 字符**（`cap < 0x10` ⇒ 内联）。
**任何把字符串字段当裸 `char*` 读的代码，只对短串有效。** → 见 `docs\05`。

> 这条布局由**两条独立工作线**得出同一结果
> （本工程 整函数级还原 与第三方 `EU4-Unicode-Patch` 的 `static_assert`）⇒ **互为印证**。

### 1.7 政体改革属性块（`obj+0x58` 起，**`0x260` 字节 = 76 个 8 字节槽**）

槽里存的是"**类型化脚本值**"指针 `v`：

```c
v == 0                                   → 返回默认
key = (*v >= 0) ? *v : ~*v               // shr eax,1Fh / cmovz
```
